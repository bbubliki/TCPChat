# 💬 TCP Chat
  
Чат-приложение на основе TCP-соединения — мобильный клиент на Android и сервер на C#.

---

## ⚙️ Технологии

| Технология | Применение |
|---|---|
| C# / .NET 9 | Язык разработки |
| .NET MAUI | Мобильное приложение (Android) |
| TCP Sockets (`System.Net.Sockets`) | Сетевое соединение |
| `TcpListener` / `TcpClient` | Сервер и клиент |
| `async` / `await` | Асинхронная работа с сетью |
| `Task.Run` | Фоновый приём сообщений |

---

## 🚀 Запуск проекта

### Требования
- [.NET 9 SDK](https://dotnet.microsoft.com/download)
- [Visual Studio 2022](https://visualstudio.microsoft.com/) с компонентом **.NET MAUI**
- Android-устройство или эмулятор

---

### 1. Запуск сервера

```bash
cd ChatServer
dotnet run
```

После запуска в консоли появится:
```
✅ Сервер запущен на порту 5000
Ожидание подключений...
```

> ⚠️ Сервер должен быть запущен **до** подключения клиентов

---

### 2. Запуск клиента

1. Открыть `ChatCLient.csproj` в Visual Studio 2022
2. Подключить Android-устройство по USB (включить режим разработчика)
3. Выбрать устройство в панели запуска
4. Нажать ▶

---

### 3. Подключение к серверу

1. Узнать IP компьютера с сервером:
   ```
   ipconfig
   ```
   Найти строку **"IPv4-адрес"** в разделе **"Беспроводная сеть"**

2. В приложении:
   - Ввести IP в поле сервера
   - Ввести имя пользователя
   - Нажать **"Войти"**

> 💡 Телефон и компьютер должны быть подключены к **одной WiFi-сети**

## 🔧 Как это работает

```
Телефон А                    Сервер                    Телефон Б
    │                           │                           │
    │── "Привет!" ─────────────>│                           │
    │                           │── "Пользователь1: Привет!"─>│
    │                           │                           │
    │<─ "Пользователь2: Ку!" ───│<── "Ку!" ─────────────────│
```

1. Клиент подключается к серверу по TCP на порт **5000**
2. Отправляет сообщение в формате `"Ник: текст"`
3. Сервер получает сообщение и рассылает его **всем остальным** клиентам
4. Каждый клиент получает сообщение и отображает его в чате
